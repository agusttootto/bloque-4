# 🦕 Parque Turístico de Dinosaurios

## 📋 Descripción del Proyecto

Simulación de un parque temático de dinosaurios desarrollada en Java 17 con Spring Boot. El sistema permite gestionar dinosaurios, visitantes, empleados, atracciones y servicios, manejando eventos aleatorios y generando reportes financieros.

## 🛠️ Herramientas Utilizadas

| Herramienta | Versión | Propósito |
|-------------|---------|-----------|
| **Java** | 17 | Lenguaje principal |
| **Maven** | 3.8+ | Gestor de dependencias y build |
| **Spring Boot** | 3.2.0 | Framework base |
| **Spring Data JPA** | - | ORM y persistencia |
| **H2 Database** | - | Base de datos embebida (desarrollo) |
| **Liquibase** | - | Migraciones de base de datos |
| **Lombok** | 1.18.30 | Reducción de código boilerplate |
| **JUnit 5** | - | Pruebas unitarias |
| **Mockito** | - | Mocking para pruebas |
| **Git** | - | Control de versiones |
